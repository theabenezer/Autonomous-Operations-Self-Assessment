Embedding the self-assessment

This is a sample host page. The assessment below is embedded by live reference, so it always reflects the newest version. It auto-resizes to fit its content: no scrollbars, no fixed height guessing. Copy the snippet below into any IBM page.

Prefer a compact inline widget without the hero banner? Append ?embed=1 to the src and the hero and footer are hidden automatically.

To open a deep dive directly, add #security, #operations or #cost to the src, for example index.html?embed=1#security.

Standalone use: just open index.html directly, or host it anywhere (it is already wired for GitHub Pages in this folder). No build step, no dependencies beyond the IBM CDN.
